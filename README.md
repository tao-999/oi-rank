# oi-rank

## USDT 永续 · 名义持仓排行榜（趋势检测）

聚合 **币安 USDT 永续合约** 的名义持仓（`Open Interest × Mark Price`），以**实时增量**与**本地历史趋势**为核心，帮助快速发现“资金显著流入/撤退”的合约标的，服务量化选币、日内跟踪与风控观察。

> 名义持仓（Notional USD）用于衡量某合约上“资金的总敞口规模”。  
> 趋势列基于本地落盘历史计算，独立于交易所的聚合“公开指标”。

## 核心价值
- **一眼看懂“哪条合约在吸金/失血”**：按名义持仓与多窗口 Δ（M/%）排序与对比。
- **更贴近“真实交易活动”**：以 OI×标记价推导名义，不依赖外部不透明指标。
- **轻量自托管**：本地服务抓取+前端可视化，历史落盘在本地文件，隐私与可控性更好。

---

## 功能清单
- **USDT 永续合约全量扫描**（TRADING、USDT 计价/保证金）
- **WS 实时更新**：标记价与资金费率（秒级）
- **名义持仓排行榜**：支持排序（名义/合约名/趋势列/市值）
- **多窗口趋势列**：可配置如 `Δ1h / 4h / 24h`（M / %）
- **历史图表抽屉**：5m～1w 粒度重采样，支持拖拽平移与滚轮缩放
- **筛选**：
  - 名义最小/最大（USD）
  - 合约名模糊（逗号/空格分隔）
  - 只看关注（⭐）
- **收藏（⭐）**：行内星标，状态存于 `localStorage`
- **市值展示（可选）**：按基础币种映射显示市值（B/M）

---

## 运行方式
- **本地运行**：安装依赖后启动服务，浏览器打开看板页面即可。
- **生产部署**：用 pm2/systemd 常驻进程，Nginx/Caddy 反代；持久化 `data/` 以保留历史。
- **环境**：Node.js ≥ 18；默认端口 `8787`（可通过环境变量覆盖）。

---

## 数据与存储
- 初始化：获取合约清单 → 批量补价与费率 → 全量拉取 OI，并落盘 `{t, oi, mp, nu}` 到 `data/*.ndjson`。
- 实时：订阅标记价/费率（1s），即时更新名义并推送前端。
- 周期：定时扫全量 OI 追加历史；前端按需读取“内存+落盘”合并去重后的历史用于趋势与图表。

---

## 前端交互
- **表格**：支持点击排序、星标收藏、复制合约名、行点击打开历史图抽屉。
- **趋势窗口**：输入 `30m,1h,4h,24h` 等，动态生成趋势列。
- **图表**：选择粒度（5m～1w）、拖拽平移、滚轮缩放；跨天场景可显示日期+时间刻度。

## 目录概览
```

server.js      Node HTTP + WS 服务
data/*.ndjson  本地历史落盘（运行期生成，不入库）
```

---

## 注意事项
- 仅统计 **USDT 永续**；交割合约/币本位永续不在范围内。
- 趋势依赖**本地历史**；首次启动或窗口跨度较大时，数据不足会显示为 `—`。
- 市值映射依赖基础币种规范化，个别小众/前缀合约可能无法匹配。
